The Checklist v2026

Broad-billed Roller Eurystomus glaucurus by Shailesh Pinto; Cornell Lab of Ornithology | Macaulay Library

AviList was released 11 June 2025 with a minor revision (2025b) on 11 June 2026. This version (v2026) is the first major revision since the initial release and was published on 20 October 2026.

As with previous versions, these files provide a consensus taxonomy combined with a full set of taxonomic and nomenclatural components, the details of which are explained at Components of the AviList checklist. Additional information is expected to be added in subsequent versions. 

AviList is free for anyone to use and download in XLSX format; the Checklist Explorer gives the additional option of non-English names and a CSV download. Note that each spreadsheet includes six tabs: AviList v2026; Decision summaries; Recommended citation; How to use; References; Changes from previous version.

This version includes the following changes from v2025:

  • Revisions based on decisions by AviList committees, including review of new taxonomic changes by TaxCom and a limited 2026 review of English names by the English Names Committee (we expect more extensive review for v2027).
  • Major sequence revisions thanks to a complete review of all orders, families, genera, and species by the AviList Sequence Committee
  • Major revisions to range statements for a large number of taxa by the Geographic Range Committee; this includes species-level range statements for all polytypic species, which is new in v2026
  • English names for orders and families, which is new in v2026; these have been ratified by the English Names Committee
  • Links to external taxonomies (eBird/Clements v2026, BirdLife v10) are updated to reflect the alignment of those taxonomies with AviList v2026. This includes changes to the following fields (English Name: Clements v2026, English Name: Birdlife v10, Extinction Status, IUCN Red List Category, Birdlife Datazone URL, Species Code Cornell Lab, Birds of the World URL).
  • All corrections for the v2025 errata, including core taxonomic fields (i.e., the errata listed under Checklist Errors) such as English name and scientific name that were not changed for v2025b.
  • All revisions from v2025b
